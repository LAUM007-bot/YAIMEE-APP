# YAIMEE POS — แอป Android (.apk)

แอป Android บางๆ ที่เปิดเว็บแอป YAIMEE ข้างใน + ปริ้นใบเสร็จเข้าเครื่อง **Sunmi InnerPrinter** ตรงๆ (กดทีเดียวพ่นกระดาษ)
เหมาะกับเครื่อง POS ที่ล็อกแอป (Ocha/Sunmi) ที่ลง RawBT ไม่ได้

---

## วิธี build เป็นไฟล์ .apk (ผ่าน GitHub — ฟรี ไม่ต้องลงโปรแกรม)

### 1. สมัคร/เข้า GitHub
ไปที่ https://github.com → สมัครบัญชีฟรี (ถ้ายังไม่มี)

### 2. สร้าง repository ใหม่
- กดปุ่ม **New** (สีเขียว) → ตั้งชื่อ เช่น `yaimee-apk`
- เลือก **Public** หรือ **Private** ก็ได้ → กด **Create repository**

### 3. อัปโค้ดขึ้นไป
- ในหน้า repo กด **uploading an existing file** (ลิงก์เล็กๆ กลางหน้า)
- **ลากทั้งโฟลเดอร์ `yaimee-apk`** (ทุกไฟล์ทุกโฟลเดอร์ข้างใน) เข้าไปวาง
- รอจนอัปครบ → กด **Commit changes**

### 4. ระบบจะ build ให้อัตโนมัติ
- ไปแท็บ **Actions** ด้านบน
- จะเห็นงานชื่อ **Build YAIMEE APK** กำลังรัน (วงกลมเหลืองหมุน) — รอ ~3-5 นาที จนเป็นเครื่องหมายถูกเขียว
- ถ้าไม่เริ่มเอง: กดเข้าไปใน workflow → ปุ่ม **Run workflow**

### 5. โหลดไฟล์ .apk
- กดเข้างานที่ build เสร็จ (ติ๊กถูกเขียว)
- เลื่อนลงล่างสุด ส่วน **Artifacts** → กด **YAIMEE-apk** เพื่อโหลด (ได้เป็นไฟล์ zip → แตกออกมาได้ `app-debug.apk`)

### 6. ลงในเครื่อง POS
- ก๊อปไฟล์ `app-debug.apk` เข้าเครื่อง Ocha/Sunmi → เปิดไฟล์ → ติดตั้ง (อนุญาต "ติดตั้งจากแหล่งที่ไม่รู้จัก" ถ้าถาม)
- เปิดแอป **ยายมี YAIMEE** → เข้าฝั่งเจ้าของร้าน → กดพิมพ์ใบเสร็จ → ออกจากปริ้นในตัวเลย

## หมายเหตุ
- แอปนี้แค่ "กรอบ" ที่เปิดเว็บ `https://yaimee-khaungnai.netlify.app/` — เวลาแก้แอป (ฟีเจอร์/หน้าตา) อัปเดตผ่าน Netlify เหมือนเดิม **ไม่ต้อง build .apk ใหม่**
- จะ build ใหม่ก็ต่อเมื่อแก้เรื่องปริ้น/ลิงก์เท่านั้น
- กระดาษตั้งไว้ **80mm (576 จุด)** — ถ้าเป็น 58mm แก้ค่า `PAPER_WIDTH` ใน `SunmiPrinter.java` เป็น `384`
- ปริ้นด้วยวิธี render ใบเสร็จเป็นรูปภาพ → ภาษาไทยไม่เพี้ยน
